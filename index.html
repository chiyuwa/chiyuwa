传统 ML 与 大模型 ICL 对比研究（2025.01–05）

设计 ICL 实验流水线：基于 SiliconFlow API 接入 Qwen2-1.5B/2.5-7B、ChatGLM3-6B、GLM-4-9B 等指令微调大模型，统一调用与结果解析流程。构建 K-shot 提示模板（5-shot/10-shot）：分类任务输出整数标签；回归任务输出实数值；采用键-值对的自然语言特征描述；在提示中加入“仅输出数值”的明确约束，设置 temperature=0 并配合 正则校验 做后处理，避免格式偏差。数据与基线设置：选择 Iris（多分类）与 California Housing（回归）两类结构化数据；对比 ICL 与 SVM /Random Forest / MLP 等 CML 基线；CML 侧做标准化与分层切分，ICL 侧保留原始可读数值并做统一评测样本抽取与脚本化评估。组织对比与归纳：从模型规模、示例数量（K-shot）、任务类型（分类/回归）、提示格式与指令清晰度四个维度总结 ICL 表现特征与脆弱点，并提出 ICL 引导 + CML 学习的混合式路线作为后续方向

技术栈： Python、SiliconFlow API、ICL、Prompt Engineering、scikit-learn
